# GrowthHigh DB Operations Dashboard

이 저장소의 GitHub Pages 주소는 로그인으로 보호된 운영 대시보드로 이동합니다. 이전 `dashboard.json`의 Cowork/Notion 수치는 더 이상 현재 운영 현황이 아닙니다.

- 기존 주소: <https://bluep2000-hub.github.io/growthhigh-recon/>
- 운영 화면: <https://dashboard.growthhigh.co.kr/>
- `index.html`: 기존 주소에서 운영 화면으로 이동하는 안내
- `dashboard.json`: 이전 방식의 호환용 기록. 현재 지표로 사용하지 않음
- `docs/hermes-orchestration.md`: Hermes 다중 에이전트 운영 구조
- `ops/hermes-orchestration/`: 공개 가능한 역할별 에이전트 지침 템플릿

## 보안 원칙

이 저장소는 공개되어 있습니다. 공개 웹 도메인을 제외한 서버 IP, 토큰, OAuth 비밀값, Discord 식별자, 원본 DB, 연락처 파일과 백업은 포함하지 않습니다.
