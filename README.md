# GrowthHigh DB Operations Dashboard

그로스하이 DB 수집·검수·Notion 적재 현황을 한눈에 확인하는 공개 대시보드입니다.

- 공개 화면: <https://bluep2000-hub.github.io/growthhigh-recon/>
- `index.html`: 대시보드 화면
- `dashboard.json`: 현재 공개 현황 데이터
- `docs/hermes-orchestration.md`: Hermes 다중 에이전트 운영 구조
- `ops/hermes-orchestration/`: 공개 가능한 역할별 에이전트 지침 템플릿
